# intelligent-writing-engine
A concise reference for intelligence writing: six core principles plus BLUF, source-bias awareness, judgment/evidence separation, IC decision-writing checklists, synthesis (1+1=3), internal formula, ACH, alternative scenarios, and full MCIIS grammar/style rules. Sources: GADINTEL, West Point, CIA, CIA/OTE, Mercyhurst (MCIIS).
